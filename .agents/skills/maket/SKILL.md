# Сделать макет

Выполни операцию `alya-vault/operations/sdelat-maket.md`. Ремесло —
`alya-vault/craft/ux-ui.md`.

## Быстрый путь

```
py -3.12 tools/maket.py landing -o work/maket.html --title "<обещание>"
```

Виды: `landing` (продающая страница), `screen` (экран приложения), `tokens`
(витрина системы: цвета, шрифты, состояния).

## Три правила, ради которых навык существует

1. **Сетка 8** — все отступы кратны восьми. Не вкус: так размеры совпадают на
   любом экране.
2. **Одна главная кнопка на экран.** Второе действие — рамка без заливки.
3. **Сначала телефон** — сузь окно до 375 px. Не работает там — не работает
   вовсе.

## Размеры, которые не нарушаются

Кнопка и поле ≥ 48 px · строка 60–75 знаков · текст ≥ 16 px · контраст
≥ 4.5 : 1 · видимая рамка фокуса.

**Пустой экран — тоже работа:** что здесь будет, почему пусто, одна кнопка.

Отдаём владельцу файлом и скриншотом. «Дизайн в фигме» не обещаем — его у
нас нет.
