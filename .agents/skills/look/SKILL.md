# Посмотреть свою работу

Операция — `alya-vault/operations/posmotret-rabotu.md`, рубрика —
`alya-vault/craft/self-review.md`. Читай их, здесь только вход.

**Правило, ради которого скилл существует:** владелец — не первый зритель
своей работы. Первый зритель — ты.

## Быстрый путь

```
python tools/look.py out/reel.mp4 -n 16          # контактный лист
python tools/teardown.py out/reel.mp4            # ритм числами
python tools/qa.py out/reel.mp4 --rhythm --cuts work/cuts.json
python tools/look.py out/reel.mp4 --frame 16.5 --safe -o work/full.png
python tools/grid_test.py out/cover.jpg          # обложка в сетке
```

## Три прохода, порядок обязателен

1. **Ритм и целое** — по контактному листу, не вчитываясь. Сколько РАЗНЫХ
   картинок? Что в первой плитке, что в последней?
2. **Цвет между планами** — тот же лист, вглядываясь. Скачки на границах
   блоков, розовое в светах.
3. **Худший кадр в полный размер** — самый светлый и самый тёмный, не самый
   красивый. Здесь судится мыло и деталь.

## Дальше

Рубрика из двенадцати вопросов, ответы строкой в `run.md`. Двенадцать «да» —
можно показывать. «Нет» — либо чинить, либо объяснить одной строкой почему
так задумано. Молчаливое «нет» — нет.
