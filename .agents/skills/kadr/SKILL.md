# Собрать кадр

Выполни операцию `alya-vault/operations/sobrat-kadr.md`. Цифры и правила —
`alya-vault/craft/kadr-elementy.md`.

## Что чем

| Показываешь | Чем |
|---|---|
| экран + лицо | `frame.py split --top … --bottom … --divider` |
| один экран | `frame.py shot --image …` |
| место на экране | `frame.py point --at x,y --box … --text "…"` |
| порядок шагов | `plate.py --layout list --upto N` (N картинок подряд) |
| результат числом | `plate.py --layout counter` |
| чужую речь | `plate.py --layout quote` |

**Сплит — прямая замена `--fit blur`:** та же площадь, но вместо размытой
копии живое лицо. Это самый дорогой хвост из найденных разбором чужих
роликов, и он закрыт 25.08.

**Крупное число — только измеренное.** Не мерено — вид не берём.

Рендерер печатает замер контраста. `БРАК` — поднимать непрозрачность
подложки, а не подбирать цвет под фон.
