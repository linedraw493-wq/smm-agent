# Сделать документ

Выполни операцию `alya-vault/operations/sdelat-dokument.md`. Форма и правила —
`alya-vault/craft/dokumenty.md`.

## Быстрый путь

```
py -3.12 tools/doc.py work/mediakit.md -o out/mediakit.html --kind mediakit
```

Виды: `mediakit`, `brief`, `report`, `offer`, `plan`. PDF — открыть в
браузере и напечатать в PDF.

## Два правила, на которых уже обожглись

**Цвета кадра не годятся для бумаги.** Палитра дома собрана под тёмный кадр;
на белом листе её светлый заголовок исчезает. В документе фон белый, текст и
заголовок тёмные, акцент фирменный.

**Прочитать целиком перед отправкой**, а не пролистать. И посмотреть, где
рвутся страницы при печати.

## Границы

Предложение клиенту (КП) — **не наш документ**: его ведёт Жаник, через Кота.

Нужен настоящий `.docx` или `.pdf` файлом — отдай markdown навыку работы с
документами. **Отправляет человек.**
