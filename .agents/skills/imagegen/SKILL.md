# Генерация изображений

Аля вызывает встроенный модуль `image_gen` **сама**. Кот не является
промежуточным звеном и подтверждение у него для генерации не требуется.

Перед вызовом зафиксируй задачу: назначение изображения, формат площадки,
сюжет, стиль, обязательный текст (дословно) и запреты. Если не хватает
некритичной детали, выбери решение по `alya-vault/brand.md` и работай.

- Новая картинка — один вызов `image_gen` с ясным production-пrompt.
- Правка существующей — сначала открой исходник через `view_image`, затем
  передай его в `image_gen`; явно перечисли, что нельзя менять.
- Готовый ассет для выпуска сохрани в его `projects/<выпуск>/work/` или
  `projects/<выпуск>/out/`, не перезаписывая существующий файл без прямого
  указания владельца.
- Для обложки после генерации всё равно пройди операцию
  `alya-vault/operations/sdelat-oblozhku.md`: AI-изображение — исходник, а не
  замена фирменному рендереру и проверке сетки.

Нельзя использовать модуль для публикации, оплаты, обхода авторских прав или
выдачи сгенерированного изображения за фотографическое доказательство.
