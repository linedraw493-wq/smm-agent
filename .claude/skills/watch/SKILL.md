# Смотреть чужое

Операция — `alya-vault/operations/uchitsya.md`. Программа — что смотреть в
каждой кафедре — `alya-vault/school/programma.md`. Здесь только вход.

## Пачкой, не по одному

```
python tools/watch.py --channel https://www.youtube.com/@nateherk/shorts -n 3
python tools/watch.py --roll-up
```

Один ролик ничему не учит: по одному замеру норму от случайности не отличить.

## Главный шаг делает не машина

`watch.py` печатает `СМОТРЕТЬ: …look.jpg`. **Открой этот файл и посмотри.**
Числа, крючок и лист машина соберёт; назвать приём словами может только глаз.

Карточка с пустыми строками «что видно глазами» = ролик скачан, но не
посмотрен. В счёт просмотров не идёт.

## Где смотрим

- **YouTube Shorts** — открыто: канал отдаёт список, всё качается без входа.
- **Instagram** — закрыто. Профили `yt-dlp` не поддерживает, реелсы просят
  вход. Работает только прямая ссылка от владельца:
  `python tools/watch.py --url <ссылка> --name 2026-08-23-avtor-chto`

Рамка тем жёсткая: IT · ИИ · автоматизация · бизнес-аналитика · дизайн ·
блокчейн. Отличный ролик вне рамки не берём.
