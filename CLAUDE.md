## Правила ремесла (короткий список, подробности в vault)

- **Цифры не выдумываются.** Порог, LUFS, crf, цвет — из
  `alya-vault/craft/`. Расходится с прозой — правит vault, не сборка на глаз.
- **Один рендерер на стиль.** Плашки и обложка рисуются одним кодом, не
  переписываются из описания.
- **Пять гейтов проходят машиной:** контраст на ярчайшем кадре · тонмап
  первым · стерео + −14 LUFS · длительность после сборки · **ритм**
  (`qa.py --rhythm`).
- **Шестой гейт — глазами, и он обязателен.** Перед показом владельцу:
  `alya-vault/operations/posmotret-rabotu.md`, контактный лист
  `tools/look.py`, рубрика из двенадцати вопросов. **Владелец — не первый
  зритель своей работы.**
- **Показать сделанное, а не спросить до.** Драфт + реальные артефакты
  владельцу → он правит → пере-гоняются только задетые шаги.
- **Тяжёлое в git не едет.** Видео, звук, шрифты — вне; в vault карточка-указатель.

## Выгрузка — репозиторий приватный

Папка — git-репозиторий с приватным remote на GitHub:
`linedraw493-wq/smm-agent`. Слово владельца 2026-08-23: «сделай проект не
публичным, это мой личный агент» и «постоянно обновляй её данные».

- **Выгружать в конце каждой сессии, где что-то менялось:**
  `powershell -ExecutionPolicy Bypass -File tools\sync.ps1`
- Автономный прогон обучения выгружает себя сам, в конце.
- **В репозиторий едет только текст и код.** `sync.ps1` останавливается,
  если в индекс попало тяжёлое: из истории git медиа потом не вынуть, не
  переписав всю историю.
- Репозиторий **не делать публичным**. Внутри — оффер, позиционирование и
  внутренняя кухня компании.
