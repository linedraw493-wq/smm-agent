# Кейс «Лидер» — карточка для актуального

**Задача:** лиды. Один кадр, который показывает решённую задачу. Призыв —
написать в директ (ставится подписью к сторис, на картинке его нет).

**Контур:** M4ksi. **Площадка:** Instagram, сторис → актуальное «Кейсы».
**Формат:** 1080×1920 PNG, безопасная коробка 900×1400 соблюдена.

## Что на карточке

- кикер: `КЕЙС · ШАХМАТНАЯ ШКОЛА «ЛИДЕР», СПБ`
- заголовок: «Школа без админки: всё в телеграме»
- подзаголовок: «Старый CRM школы умер от интерфейса. Новый мы построили без него.»
- два столбца «было / стало»
- четыре цифры: 20 · 43 · 9 · 5
- итог: пилот развёрнут и отвечает, выкатки зелёные; два сквозных прогона

## Каждая цифра — чем проверена

Правило [[../../alya-vault/judgment|judgment]]: число называется, только если
измерено. Мерено 2026-08-26 по `C:/leader/leader-chess-api/`.

| Цифра | Чем измерена |
|---|---|
| 20 таблиц | `grep -oiE "create table..." migrations/*.sql`, без служебной `schema_migrations` |
| 43 ручки API | `grep -oE "@[a-z_]+\.(get|post|patch|put|delete)\(" api/` |
| 9 команд бота | `Command("...")` в `bot/`: leads · card · lead · status · calls · trials · stats · who · funnel |
| 5 служб стенда | `docker-compose.yml`: web · site · api · bot · db |
| 2 сквозных прогона | `test/smoke.sh` (путь заявки) и `test/school.sh` (школьная половина) |
| пилот отвечает | `chess-system-vault/deploy.md`: Railway, 4 службы, выкатки `SUCCESS`, схема до `014` |

Формулировки «было» взяты из ТЗ школы (`leader-llm-wiki/spec/README.md`):
операционка переезжает из markdown в базу; старый CRM «умер от фронта»; заявок
и пробных в старой схеме не было.

## Чего на карточке намеренно нет

- **«Проект сдан»** — неправда: боевой контур не развёрнут, миграция вики → базу
  и сдача не начаты. Карточка говорит «пилот», а не «сдали».
- **Денег** — модуля денег в системе нет вовсе, цифру про кассу называть нечем.
- **Персональных данных** — ни учеников, ни родителей, ни сумм. Граница проекта.
- **Логотипа школы и скриншотов с людьми** — согласия на использование марки
  клиента в рекламе нет, слова владельца тоже. Названа только школа и её
  публичный сайт.
