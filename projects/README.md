# projects — выпуски

Папка на ролик: `ГГГГ-ММ-ДД-короткое-имя/`. Внутри всегда одно и то же:

```
script.md   сценарий: крючок, биты, текст, тайминг, что в кадре
raw/        сырьё как пришло — не трогается никогда (вне git)
work/       промежуточное: words.json, subs.ass, чистый звук, срезы (вне git)
out/        готовый вертикальный файл + обложка (вне git)
run.md      что вышло: гейты, правки владельца, грабли, цифры после публикации
```

`run.md` — не отчёт для галочки, а **петля обучения**: из него растут дельты
в `alya-vault/craft/`. Прогон без `run.md` — потерянный опыт.
