# Астана 28.08.26 — карта монтажа

**Контур:** M4ksi. **Повод:** поездка на консультацию бизнеса по новым
проектам. **Звук:** голос владелец пишет сам поверх готовой картинки.

**Готово: `out/astana-v3.mp4` — 19.17 с, 7 планов, 1080×1920.**
Первая версия (`out/astana-v1-staraya.mp4`, 26.7 с) забракована владельцем:
«фотка ублюдская, качество дерьмо, кадры резкие и рваные, слишком много
дороги». Что сделано по каждому пункту — в [[run]].

## Ритм — числами

Мерено на версии встык (`work/clip-hard.mp4`), потому что мягкие переходы
детектор склеек не видит — об этом прямо предупреждает `qa.py`:

```
планов          7
средний план    2.61 с   (норма ≤ 3.0)
самый длинный   4.00 с   (норма ≤ 5.0)
первая склейка  1.90 с   (норма ≤ 2.0)
длины планов    1.9 · 4.0 · 3.0 · 3.2 · 3.4 · 3.0 · 2.3
```

Разброс длин намеренный: ровный ряд читается метрономом.

## Потолок этого материала

Из 127 секунд сырья **90 секунд сняты из машины**. Не из машины — только
двор (21 с, один и тот же проход спиной) и кафе (16 с, одна точка, одна
крупность). Поэтому доля дороги опущена до 47 %, ниже — уже нечем заполнять.

**Третья правка владельца — «видео с походкой уменьши».** Двор был двумя
планами на 7.2 с (33 % ролика), стал одним на 3.4 с (18 %). Заменить его
нечем: кафе выбрано целиком, а первые десять секунд `v1` непригодны — рука
собеседника стоит кулаком в середине кадра, кроп её не обходит ни при каком
положении рамки (проверено, `work/f-v1-krop.jpg`). Поэтому ролик стал
короче: 19.2 с вместо 21.8.

Чтобы поездка выглядела как поездка на консультацию, а не как дорога,
нужны кадры **с места**: как заходите, общий план кафе, руки и ноутбук
крупно, блокнот, кофе, лицо клиента, момент договорённости. Сейчас вся
встреча — один кусок с одной точки.
