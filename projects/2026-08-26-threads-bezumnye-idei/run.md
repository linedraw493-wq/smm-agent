# Run — безумные идеи постов Threads

**Задача:** слово владельца 2026-08-26 — «нужна генерация безумных идей для
постов в threads».

**Как прочитала.** Партия от 24.08 (`2026-08-24-threads-posts-01`) закрыла
нормальный контур: кейс, оффер, обучение, три возражения, бренд. Просьба про
«безумные» — не про другую тему, а про **другую форму**: то, что в той партии
осознанно не делалось. Темы держатся в рамке владельца (IT, ИИ,
автоматизация, бизнес-аналитика, дизайн, блокчейн), тон анти-хайповый по
[[../../alya-vault/brand]], числа — только замеренные ([[../../alya-vault/judgment]] п.4).

**Что сделала:** 30 заходов в семи группах — радикальная прозрачность ·
провокация на ответ · анти-продажа · форматы-мутанты · сериалы · плюс отбор
семёрки на первую неделю. Каждый заход: первая строка, тело, зачем, чем
безумен, что нужно от владельца.

**На чём построено, а не выдумано:**
- Сигналы Threads из [[../../alya-vault/trends/platform-signals]]: площадка
  считает **скорость ответов в первые минуты** и награждает участие, а не
  вещание. Отсюда рычаг всей партии — пост, на который нельзя молча
  лайкнуть, и ветка-сериал вместо одиночного поста.
- Правило первой строки из [[../../alya-vault/craft/hooks-and-formats]]:
  в ленте видно только её.
- Своё производственное сырьё как честный материал для «безумия»: шесть
  гейтов, брак ролика, корпус из 24 разобранных роликов, логи. Это правда,
  и подделать её конкурент не может.

**Границы, которые держала.** Ни одного выдуманного числа: где число нужно
владельца — стоит пометка «нужен замер / нужно от тебя». Кейс школы «Лидер»
не брала (чужая дверь, статус `draft`). Персональных данных в логах (идея 21)
не выйдет. Конкурентов по имени не задеваем.

**Возражение, записанное заранее.** Четыре идеи (7, 28, 29, 30) — сериалы на
неделю-месяц. Начать и бросить хуже, чем не начинать: Threads снимает
видимость с аккаунта, который обещал ежедневную ветку и пропал. Запускаем
только с прямым «да» владельца на срок.

**Отдано владельцу:** `posts.md` файлом в сессии. Файл вне git
([[../../alya-vault/decisions/2026-08-23-posty-ne-v-git]]) — проверено
`git check-ignore`. **Не публиковала**: постинг закрыт словом владельца.

**Дальше:** владелец называет номера — разворачиваю в готовые тексты по
операции [[../../alya-vault/operations/napisat-post]] (первая строка, тело,
один призыв, 3–5 честных тегов).
