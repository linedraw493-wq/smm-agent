# tools — код, который исполняет ремесло

Шов простой: **конвейер называет гейт → ремесло даёт порог → код исполняет.**
Пороги и цифры живут в `../alya-vault/craft/`. `config.py` — единственное
место, где они превращаются в константы. Число расходится с craft → правит
craft, код догоняет.

| Модуль | Что делает |
|---|---|
| `config.py` | все константы: цвета, геометрия, LUFS, crf, пороги |
| `doctor.ps1` | проверка стека перед сборкой; ловит подменённый slim-ffmpeg |
| `transcribe.py` | речь → `words.json` со словными таймингами |
| `subs_ass.py` | `words.json` (+ `cuts.json`) → `subs.ass` в стиле дома |
| `audio_clean.py` | чистка голоса + стерео + −16 LUFS |
| `build_reel.py` | сборка вертикали: тонмап → плашки → сабы → фейд → экспорт |
| `qa.py` | гейты готового файла; выход 1, если брак |

Чего здесь ещё нет: `plate.py` — общий рендерер плашек и обложки. Он ждёт
шрифтов ([[../alya-vault/backlog]]): писать рендерер без шрифтов, которыми он
будет рисовать, — значит писать вслепую.

`models/` — модели распознавания, вне git, качаются сами при первом запуске.

## Разбор чужого и выгрузка

| Модуль | Что делает |
|---|---|
| `ref_get.ps1` | скачать чужой ролик на разбор в `assets/ref/` (yt-dlp) |
| `teardown.py` | замеры чужого ролика: LUFS, LRA, склейки, средний план |
| `grid_test.py` | проверка обложки в сетке 3:4 — читается ли размером с ноготь |
| `sync.ps1` | выгрузить накопленное в приватный репозиторий на GitHub |

`sync.ps1` **останавливается**, если в индекс попало тяжёлое. Репозиторий
должен остаться текстовым: из истории git медиа потом не вынуть, не
переписав всю историю.

## Цвет и звук

| Модуль | Что делает |
|---|---|
| `palette.py` | палитры-кандидаты: `ink-lime`, `blue-white`. Цвет **не зашит в код** |
| `audio_report.py` | замер голоса до обработки: полосы, потолок, LUFS, шум |
| `audio_polish.py` | чистка, эквализация, де-эссер, пространство, стерео, громкость |

`audio_clean.py` — простая цепочка без эквализации, оставлена для случаев,
когда голос уже хорош и нужен только мастеринг. Для всего остального —
`audio_polish.py`.

Палитра не выбрана: владелец и Нурс держат два варианта. Любой модуль
принимает `--palette`, по умолчанию берётся `ALYA_PALETTE` или `ink-lime`.

## Кадрирование, каты, картинка, музыка

| Модуль | Что делает |
|---|---|
| `plate.py` | **один рендерер**: обложка, плашка, нижняя треть; гейт контраста внутри |
| `cuts.py` | карта катов из длинного материала — механический слой, часы не страшны |
| `music_bed.py` | музыка под голос: уровень, вырез в полосе речи, приседание |

`build_reel.py` вырос: `--cuts` применяет карту, `--fit` выбирает
кадрирование (запись экрана **вписывается**, а не режется), `--look` и
`--quality` дают насыщенную детальную картинку по умолчанию.

Два предела, найденных прогоном и обойдённых в коде:

- выражение `select` не переваривает больше ~40 кусков — выше сборка сама
  переходит на `trim+concat`;
- `.ps1` без BOM Windows PowerShell читает как ANSI и ломается на кириллице —
  все скрипты записаны с BOM.

## Telegram

`tg_read.py` — **только чтение** чатов владельца. Своего кода почти нет:
зовёт готовый читатель из `jabjik/tools/tg-reader/`, чтобы не заводить второй
экземпляр. Доступы и сессию инструмент находит сам, Аля их не видит.

Отправку обёртка отклоняет. Вход выполняет владелец, один раз, сам.
Выгруженная переписка идёт в `work/` — вне git, это личные данные.
