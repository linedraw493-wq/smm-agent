# SMM агент — Аля

Личный агент **Алёна (Аля)** компании **M4ksi**: реклама, SMM, маркетинг,
монтаж видео и звука, субтитры, обложки, тексты, комментарии.

Репозиторий приватный. Здесь только **знание и код** — медиа, шрифты и
модели распознавания в него не едут по построению (`.gitignore`).

## Вход

**Дверь — [`CLAUDE.md`](CLAUDE.md).** Открой её первой: там кто такая Аля,
что можно и чего нельзя.

Дальше — [`alya-vault/HOME.md`](alya-vault/HOME.md), карта её головы.

## Что внутри

| Папка | Что |
|---|---|
| `alya-vault/` | голова: ремесло, операции, решения, позиция, обучение |
| `tools/` | модули конвейера: транскрипт, субтитры, звук, сборка, гейты, разбор чужого |
| `presets/` | стиль субтитров |
| `projects/` | выпуски (содержимое вне git) |
| `assets/` | шрифты, музыка, логотипы (вне git) |

## Быстрый старт на новой машине

```
powershell -ExecutionPolicy Bypass -File tools\doctor.ps1
```

Проверяет стек: ffmpeg full-build, Python, `faster-whisper`, `pysubs2`,
Pillow, шрифты. Не прошло — чинить, не собирать.

Шрифты в репозиторий не входят: Inter (Regular/SemiBold/ExtraBold) и
Playfair Display (SemiBold/SemiBoldItalic), только **static TTF**, кладутся
в `assets/fonts/`. В систему ставить не надо — ffmpeg берёт их через
`fontsdir`.
