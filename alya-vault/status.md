# Состояние на 2026-08-23

Аля **заведена сегодня**. Живых прогонов ещё не было — ни одного ролика.

## Что стоит и работает

- Папка, дверь, vault, операции, скиллы — есть.
- Стек монтажа поставлен и проверен на этой машине: ffmpeg 9.0 full-build
  (фильтры `ass`, `zscale`, `tonemap`, `loudnorm`, `arnndn`, `afftdn`,
  `sidechaincompress` на месте), Python 3.12, `faster-whisper`, `pysubs2`,
  `Pillow`, `yt-dlp`.
- Ремесло цеха перенесено в `craft/` с поправкой на Windows.
- Автономное обучение включено: задача `alya-trend-scan`, понедельники.
- Конвейер прогнан насквозь на тестовом клипе: субтитры, звук, сборка —
  все четыре гейта зелёные. На живом материале ещё не гонялся.
- Своё мнение записано — [[judgment]].
- **Шрифты поставлены** 2026-08-23: Inter (Regular/SemiBold/ExtraBold) и
  Playfair Display (SemiBold/SemiBoldItalic) нарезаны из вариативных в
  статические TTF, кириллица полная. Лежат в `assets/fonts/`, ffmpeg берёт их
  параметром `fontsdir` — **в систему ставить не потребовалось**.
- **Субтитры проверены рендером:** Inter, кириллица, плашка, контраст 9.5
  при пороге 6.6. Тест поймал две тихие ошибки формата ASS — обе исправлены
  и записаны в ремесло.
- **Палитра расфиксирована — их две.** Слово владельца: дизайн не выбран,
  его вариант чёрный с лаймом, у Нурса синий с белым. Цвет вынесен из кода
  в `presets/palette-*.json`, любой модуль работает с любой палитрой
  ([[craft/design-system]]). По умолчанию `ink-lime`.
- **Звук углублён.** `audio_report.py` — замер по шести полосам, ловит
  потолок 10 кГц (подпись мессенджера). `audio_polish.py` — эквализация,
  динамический де-эссер, пространство, стерео, громкость. Проверено на живом
  войсовере: присутствие +5.0 dB, воздух +5.6 dB, разборчивость +3.1 dB,
  −15.9 LUFS, пик −1.0 dB. Совпадает с целью канона (+4…+6 dB на 3–10 кГц).
- **Субтитры раскладываются по кадрам.** `subs_ass.py --scenes`: карта,
  перепрыгивающая склейку, режется по ней. Проверено — режет. Плюс акцент на
  ключевом слове, числа выделяются сами.
- **Выгружена на GitHub:** `linedraw493-wq/smm-agent`, приватный. Обновление
  через `tools/sync.ps1`, автономный прогон выгружает себя сам.
- **Инструменты разбора чужого готовы и проверены** на живом референсе:
  `tools/teardown.py` сошёлся с ручным разбором цеха до десятых (−14.5 LUFS,
  LRA 2.1). `tools/grid_test.py`, `tools/ref_get.ps1`.
- Модель хранения решена — [[decisions/2026-08-23-hranenie-i-segmentaciya]].
- Vault открыт в Obsidian: волт зарегистрирован на корень `reelsmaker/`.
