# Карточка кейса рисуется светлой, а не на графите

**Слово владельца 2026-08-26.** Он прислал переделанную карточку кейса «Лидера»
и сказал: «вот тебе база, на которую следует смотреть при дизайне». Дальше
кейсы собираются по ней.

## Что изменилось

Было (решение [[2026-08-24-vybor-palitry]]): графит `#0a1929`, синий акцент,
тёплый кремовый текст. Стало — для этой поверхности:

| Роль | Цвет |
|---|---|
| фон кадра | `#f2efe8` — тёплый кремовый |
| карточка | `#f8f6f1`, рамка `#e4e0d6`, скругление 26 px |
| текст | `#16181a` |
| вторичный текст | `#71736c` |
| акцент | зелёный `#3f5d40` |
| «плохая» метка | серый `#8f918a` / `#a3a59d` |

Строй кадра тоже задан эталоном: кикер с разрядкой → заголовок в три строки,
третья акцентом → подзаголовок → два столбца «было/стало» карточками с
иконками → полоса из четырёх цифр → итог с круглой иконкой → подвал с маркой.

## Почему не спорю

Светлое здесь работает лучше тёмного по делу, а не по вкусу: кейс читают
дольше рилса, а тёмный фон с длинным текстом утомляет глаз. Скруглённые
карточки и иконки разбивают текст на куски, которые видно за секунду.
Правило «акцент один» не нарушено — зелёный в кадре единственный.

## Что это НЕ отменяет

- **Видео.** Ролики остаются на графите с синим: эталон был статичной
  карточкой, про видео владелец не говорил. Спросить прямо, когда дойдёт
  до обложек роликов.
- **Тон.** Анти-хайп, цифрами процесса, число только измеренное — без
  изменений.
- **Безопасную зону.** Эталон нарисован во весь кадр; для сторис и актуального
  макет ужимается в 900×1400, иначе верх и низ съест интерфейс площадки.

## Хвост

Светлые цвета пока живут в `:root` макета
`projects/2026-08-26-keys-tendery/work/case.html`, а не в `presets/`. Пойдёт
третий кейс — вынести пресетом, иначе два источника цвета разойдутся.
