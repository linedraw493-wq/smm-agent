# Решение — как раскладываются файлы Али

**Что есть по факту** (замер 2026-08-23): один физический диск **C:**, 953 ГБ,
свободно **347 ГБ**. Второго диска в машине нет. Значит «сегментация по
дискам» сегодня невозможна физически — раскладка идёт **по роли файла и по
границе git**, и это правильнее: буква диска ничего не гарантирует, а роль —
гарантирует.

## Четыре класса файлов, четыре судьбы

| Класс | Что это | Где | Git | Живёт |
|---|---|---|---|---|
| **Знание** | vault: ремесло, операции, решения, позиция, тренды | `alya-vault/` | да | вечно |
| **Код** | модули конвейера, пресеты | `tools/`, `presets/` | да | вечно |
| **Работа** | сырьё, промежуточное, готовое по выпуску | `projects/<выпуск>/` | нет | по циклу ниже |
| **Общее тяжёлое** | шрифты, музыка, SFX, логотипы | `assets/` | нет | вечно, но вне git |

Правило одной строкой: **в git едет то, что можно прочитать глазами. Всё,
что весит, — мимо.** Иначе папка станет неподъёмной за месяц, а история
git — бесполезной.

## Цикл жизни медиа — иначе диск кончится

Один выпуск с телефонным сырьём — это единицы гигабайт. При двух роликах в
неделю 347 ГБ уходят примерно за год, и это оптимистично.

1. **Пока выпуск в работе** — всё на месте: `raw/`, `work/`, `out/`.
2. **Через 14 дней после публикации** — `work/` **удаляется целиком**. Он
   пересобирается из `raw/` за минуты; хранить его незачем.
3. **Через 60 дней** — `raw/` уезжает в холодную папку `_archive/` рядом.
   `out/` и `script.md` с `run.md` остаются: готовый ролик лёгкий, а знание
   о нём — вообще текст.
4. **Удаление `raw/` — только по слову владельца.** Исходники не
   восстанавливаются, это необратимое.

Аля **предлагает** уборку и показывает, что и сколько освободит. Не чистит
сама: удаление чужой работы — не её рука.

## Чего сознательно не делаем

- **Не раскладываем по вторым дискам** — их нет. Появится внешний — переедет
  `_archive/`, целиком и одним движением; остальное не тронется.
- **Не заводим git-remote** — по образцу уровня владельца, база локальная.
  Цена та же и она серьёзная: **копии за пределами этой машины нет**. Сгорит
  диск — сгорит и знание Али, и весь архив выпусков. Строка стоит в
  [[../backlog]] и ждёт слова владельца.
- **Не тащим медиа в git даже «на минуту»** — из истории git оно потом не
  вынимается без переписывания всей истории.

## Почему vault отдельно от projects

Знание переживает выпуски. Через год роликов будет сто, а `craft/` останется
тем же десятком файлов — только точнее. Смешать их значит потерять и то и
другое: знание утонет в папках выпусков, а выпуски нельзя будет чистить, не
задев знание.
