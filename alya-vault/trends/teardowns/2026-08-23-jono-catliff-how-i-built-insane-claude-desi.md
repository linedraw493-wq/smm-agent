# Разобрано глазами 2026-08-23 (Кот)

**Что видно на листе**

- **Сплит верх/низ весь ролик.** Второй ролик того же автора — раскладка та
  же, значит это не приём одного видео, а его формат.
- **Первый кадр — мозаика чужих экранов**, не лицо. Показывает результат до
  того, как объяснит.
- **Субтитров нет.** Держит экран.
- **Верх меняется каждые 2–3 секунды**: логотип → интерфейс → каталог токенов
  → окно промпта → готовый сайт. Это и есть монтаж.
- **Цвет:** дневной нейтральный, мягкий, фон размыт по-настоящему, кожа
  чистая. Ни фильтра, ни резкости.
- **Финал:** лицо, кадром, без затухания.

**Мост к нам**

- **Что забираем:** (1) результат в первом кадре, объяснение потом —
  сильный ход для «экрана-доказательства»; (2) сплит как постоянный формат
  рубрики, а не разовый приём; (3) темп смены верхней половины 2–3 секунды.
- **Чего не забираем:** отсутствие субтитров — только при живом экране.
