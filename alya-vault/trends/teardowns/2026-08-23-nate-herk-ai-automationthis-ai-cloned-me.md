# Разобрано глазами 2026-08-23 (Аля) — ДУБЛЬ, разбор не здесь

**Это тот же самый ролик, что и
[[2026-08-23-na-this-ai-cloned-me-in-15-second]].** Не похожий — тот же файл.

```
источник обоих   https://www.youtube.com/watch?v=rhv61m8n3Nc
md5 обоих src.mp4  ad2dbd5468fb4adfecf94a3960ecbe73
```

**Разбор глазами живёт в той карточке**, дублировать его здесь — значит
завести две версии правды, которые потом разойдутся.

**Как это вышло.** `watch.py --channel` берёт автора из плоского списка
YouTube, а там поле `uploader` то заполнено, то пусто. Один и тот же ролик
пришёл один раз как «Nate Herk», другой раз как «NA» — и лёг в две папки,
потому что имя папки складывается из автора и заголовка. Проверки «этот id
уже скачан» в модуле нет.

**Что с этим сделано в прогоне 2026-08-23:**

- Установлено, что **все карточки с автором `NA` — не безымянные**:
  `na-this-ai-cloned`, `na-practice-any-hard`, `na-never-miss-a-customer-call`
  — это **Nate Herk**; `na-alex-hormozi-on-how-to-make-a` — **Liam Ottley**.
  Поля `автор:` исправлены по спискам каналов.
- В `watch.py` закрыта ловушка пострашнее: карточка со словами «Разобрано
  глазами» больше **не перезаписывается** повторным прогоном.
- Хвост «дедупликация по id ролика» — в [[../../backlog]].

**Файлы этой папки не удаляю сама**: `assets/ref/` вне git, чистка чужого
скачанного — не автономное решение. Строка владельцу в `inbox/`.
