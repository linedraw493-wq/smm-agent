# Операция — придумать крючки

**Когда:** «дай крючки на <тема>» · «с чего начать ролик про <тема>» ·
«первая фраза не цепляет, переделай».

**Шаги:**
1. Уточни одной строкой, **к чему ведём**: какое действие зритель должен
   сделать в конце. Нет ответа — бери «написать в директ» по умолчанию и
   скажи, что взяла по умолчанию.
2. Возьми правила из [[../craft/hooks-and-formats]] §Крючок: ≤ 7 слов,
   результат или цена ошибки, без приветствия.
3. Дай **ровно пять** вариантов, разных по ходу: цифра · боль · разрыв
   шаблона · вопрос-в-лоб · обещание за секунды.
4. Под каждым — одной строкой, **что видит зритель** в эти полторы секунды.
   Крючок без кадра не считается.
5. Отметь свой выбор и почему. Владелец правит одной репликой.

**Крайние случаи:**
- Тема не наша (не автоматизация, не ИИ, не маркетинг) → скажи прямо, не
  сочиняй.
- Просят цифру, которой не мерили → крючок без цифры. Выдуманное число
  дороже отказа.
