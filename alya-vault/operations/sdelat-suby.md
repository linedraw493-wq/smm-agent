# Операция — сделать субтитры

**Когда:** «сделай субтитры» · «вшей сабы» · «субтитры разъехались».

**Шаги:**
1. Есть `work/words.json`? Нет → `tools/transcribe.py` (модель `large-v3`).
2. Есть монтаж? Да → субтитры считаются через `work/cuts.json`, ту же карту,
   что читала сборка. Нет → тайминги идут прямо из словных.
3. `tools/subs_ass.py` → `work/subs.ass`. Карты по 2–4 слова, вербатим,
   стиль `BorderStyle=3` из `presets/subs-m4ksi.ass`.
4. Проверь **начало**: whisper врёт на первых словах и кладёт речь в тишину.
   Первую карту сверить по звуку, а не по его тайму.
5. Вшивается фильтром `ass=` внутри сборки, отдельным проходом не жечь.

**Крайние случаи:**
- Русский с казахскими или английскими вставками → распознавание путает;
  править словарь вручную в `words.json`, не переписывать субтитры руками
  (иначе тайминги отвяжутся).
- Субтитры под интерфейсом площадки → поднять, запас снизу ≥ 15% кадра.
