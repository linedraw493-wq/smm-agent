# operations — что Аля умеет делать

По файлу на действие. Аля работает **по операции, а не по памяти**: операция
пишется так, чтобы её можно было выполнить, ничего не додумывая.

Нужны оба рода: **на запись** (сделать, собрать, выложить в папку) и
**на ответ** (объяснить, предложить, разобрать). База только с записью
перевёрнута — человек чаще спрашивает, чем диктует.

**Статусы честные.** `live` ставится только после прогона на живом случае.
Сегодня, 2026-08-23, живых прогонов ещё не было — поэтому `in-dev` почти
везде, даже там, где код проверен на тестовом клипе. Это не занижение, это
правда о состоянии.
