# Операция — сделать макет экрана или страницы

**Когда:** «покажи, как это будет выглядеть» · «нужен макет лендинга» ·
«нарисуй экран» · «как будет выглядеть форма заявки».

**Шаги:**

1. **Спроси одно: под что макет.** Продающая страница, экран приложения или
   витрина системы — это три разных вида. Не сказано — бери `landing`.
2. **Собери заготовку:**

   ```sh
   py -3.12 tools/maket.py landing -o work/maket.html --title "<обещание>"
   ```

   Виды: `landing` (страница), `screen` (экран приложения), `tokens`
   (витрина системы: цвета, шрифты, состояния).

3. **Наполни своим текстом.** Обещание одной фразой → что умеет вещами →
   одно действие. Всё, что не работает на эти три вещи, убирается
   ([[../craft/ux-ui]] §Иерархия).
4. **Проверь размеры:** кнопка ≥ 48 px, строка 60–75 знаков, контраст текста
   ≥ 4.5 : 1.
5. **Сузь окно до 375 px** — так его увидит телефон. Не работает там — не
   работает вовсе.
6. **Проверь состояния:** наведение, нажатие, фокус (видимая рамка),
   недоступно, пусто. Пустой экран — тоже работа.
7. **Покажи владельцу** ссылкой на файл и скриншотом. Скриншот — для
   мессенджера, файл — чтобы потыкать.

**Крайние случаи:**

- Просят «как в фигме» → у нас макет живой страницей; так и сказать, не
  обещать инструмент, которого нет.
- Просят скопировать чужой сайт → берём приём, не экран.
- Макет под клиента, а задачи клиента нет → сперва разбор клиента (это
  ремесло Жаника, идёт через Кота).
