# Операция — собрать кадр из элементов

**Когда:** «сделай сплит с экраном» · «покажи скриншот красиво» · «поставь
стрелку сюда» · «нужен список по шагам» · «крупное число в кадр» ·
«поставь цитату».

Все элементы и их цифры — [[../craft/kadr-elementy]].

**Шаги:**

1. **Реши, что показываешь.** Экран + лицо → сплит. Один экран → скриншот на
   подложке. Место на экране → указатель. Порядок шагов → накопительный
   список. Результат → крупное число. Чужая речь → цитата.
2. **Собери:**

   ```sh
   py -3.12 tools/frame.py split --top work/screen.png --bottom work/face.png --divider
   py -3.12 tools/frame.py shot  --image raw/dash.png -o work/shot.png
   py -3.12 tools/frame.py point --image work/shot.png --at 620,880 --text "сюда"
   py -3.12 tools/plate.py --layout list    --text "раз; два; три" --upto 2 -o work/l2.png
   py -3.12 tools/plate.py --layout counter --text "20 из 24" --note "<что значит>"
   py -3.12 tools/plate.py --layout quote   --text "..." --note "<кто сказал>"
   ```

3. **Прочитай замер контраста**, который печатает рендерер. `БРАК` — поднять
   непрозрачность подложки или сменить цвет текста, **не** «подобрать под
   фон».
4. **Для видео-сплита** возьми команду `tools/frame.py split --cmd` и вставь
   её в сборку — модуль сам ничего не рендерит.
5. **Накопительный список** — это N картинок (`--upto 1..N`), которые ставятся
   подряд. Одна картинка со всем списком сразу — другой приём и работает хуже.
6. **Посмотри глазами** перед показом: [[posmotret-rabotu]].

**Крайние случаи:**

- Число не мерено → крупное число не берём вовсе. Правило дома.
- Сплит с неподвижным низом → гейт ритма его не считает: смена верхней
  панели для детектора не событие. Хвост в [[../backlog]].
- Скриншот с чужими данными → закрыть или взять другой.
