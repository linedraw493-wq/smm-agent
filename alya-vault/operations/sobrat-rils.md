# Операция — собрать рилс

**Когда:** «собери ролик» · «смонтируй из того, что в raw» · «пересобери
с правками».

**Шаги:**
0. **Назови палитру.** Она не выбрана — их две ([[../craft/design-system]]).
   Палитра выпуска пишется в `run.md`, иначе через месяц не понять, чем
   собран ролик.
1. `tools/doctor.ps1` — проверка стека. Не прошла → чинить, не собирать.
   Главная ловушка: подменённый slim-ffmpeg, тогда падает фильтр `ass`.
2. Разложи сырьё в `projects/<выпуск>/raw/`. **Сырьё не трогается никогда** —
   всё промежуточное пишется в `work/`.
3. `tools/transcribe.py` → `work/words.json` (словные тайминги).
4. Собери карту катов `work/cuts.json`. Она **единственный источник правды**
   по таймингу: её читают и сборка, и субтитры ([[../craft/subtitles]]).
5. Параллельно, они друг друга не ждут:
   - звук — по [[obrabotat-zvuk]]: сначала замер, потом обработка;
   - `tools/subs_ass.py --scenes work/clip.mp4` → `work/subs.ass`
     (карты раскладываются по кадрам, не только по времени);
   - обложка — по [[sdelat-oblozhku]];
   - подпись — по [[napisat-post]].
6. `tools/build_reel.py` → `out/<имя>.mp4`. Внутри жёсткий порядок:
   **тонмап → плашки → субтитры → фейд → экспорт** ([[../craft/video-station]]).
7. `tools/qa.py` — четыре гейта. Не прошёл — не показывать, чинить.
8. Покажи владельцу ролик, обложку и подпись вместе (чекпоинт
   [[../pipelines/streams]]). Правки → пере-гоняй **только задетые шаги**.
9. Закрой выпуск по [[zakryt-vypusk]].

**Крайние случаи:**
- Длительность после сборки не сошлась с картой катов → рассинхрон concat,
  тихий брак. Пересобрать, не «подрезать в конце».
- Голос записан через мессенджер → полосу выше 10 кГц не вернуть. Сказать
  владельцу прямо и просить перезапись ([[../craft/audio]]).
